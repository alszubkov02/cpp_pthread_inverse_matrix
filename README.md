Метод Жордана поиска обратной матрицы с выбором главного элемента по строке реализован с использованием параллельных вычислений 
на основе библиотеки pthread и блочного хранения матрицы для повышения производительности и эффективного использования кэш-памяти.

Блочное хранение предполагает разбиение матрицы на блоки фиксированного размера, которые последовательно располагаются в памяти. 
Это позволяет минимизировать количество промахов кэша при выполнении операций над строками и столбцами, так как данные, участвующие в преобразованиях, загружаются компактными порциями и многократно используются.
Каждый блок представляет собой непрерывный участок памяти, что особенно важно при распараллеливании, поскольку потоки могут независимо обрабатывать различные блоки без конфликтов доступа.

Параллелизация организована на уровне обнуления элементов текущего столбца. 
После выбора главного элемента и нормирования ведущей строки, выполняемых последовательно в силу их зависимости, создаётся пул потоков, каждый из которых отвечает за обработку своей группы строк. 
Потоки выполняют операцию вычитания ведущей строки, умноженной на коэффициент, из всех элементов соответствующих им строк, работая независимо друг от друга. 
При блочном хранении это означает, что каждый поток обрабатывает блоки данных, закреплённые за его строками, что обеспечивает равномерную загрузку вычислительных ядер и эффективное использование кэш-памяти. 
Синхронизация между потоками требуется только после завершения обработки всех строк, перед переходом к следующему шагу алгоритма.

Алгоритмическая сложность метода остаётся O(n³), однако использование параллельных вычислений позволяет достичь значительного ускорения, близкого к количеству задействованных ядер, за счёт независимой обработки строк. 
Пространственная сложность составляет O(n²) с учётом блочного представления, которое не увеличивает общий объём памяти, но улучшает локальность доступа. 
Выбор главного элемента по строке гарантирует численную устойчивость метода, а блочное хранение и распараллеливание делают его эффективным для матриц большой размерности, позволяя достичь высокой производительности в многопроцессорных системах.
